# OntoDL+

Language support for OntoDL+ ontologies in VS Code. Open a `.odlp` file to get diagnostics, completion, hover, go to definition, find references, rename, an outline, and folding.

## Development

Install dependencies with `npm ci`, then compile with `npm run compile`. In VS Code, run the `Launch Client` configuration and open a `.odlp` file in the extension host.

Contribution rules are in `CONTRIBUTING.md`.
